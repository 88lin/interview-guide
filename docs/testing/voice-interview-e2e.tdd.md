## 覆盖率与已知缺口

当前前端没有覆盖率脚本；本次未生成数值覆盖率。测试显式 Mock 了 REST、WebSocket、VAD 和浏览器虚拟麦克风，因此不覆盖真实 ASR/LLM/TTS 供应商的网络协议。真实供应商应作为独立、低频的环境冒烟测试运行，避免进入每个 PR 的确定性回归门禁。
